# Convert lists in a reference profile to vectors

Use for elements like keywords and subjects that are returned as lists
of single-element lists

## Usage

``` r
.lists2vectors(parent_list, child_list_names)
```

## Arguments

- parent_list:

  The list representing the reference profile

- child_list_names:

  The elements of the reference profile that should be converted to
  vectors

## Value

The tidied reference profile
