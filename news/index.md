# Changelog

## NPSdatastore (development version)

- [`.datastore_request()`](https://doi-nps.github.io/NPSdatastore/reference/dot-datastore_request.md)
  now includes a `verbose` option that prints the API request info to
  the console, and this can be enabled for any function in the package.
  It is, in fact, verbose, so don’t use this option unless you are
  debugging and truly need diagnostic info regarding the API request.
- [`.datastore_request()`](https://doi-nps.github.io/NPSdatastore/reference/dot-datastore_request.md)
  now adds a user-agent string identifying this package
